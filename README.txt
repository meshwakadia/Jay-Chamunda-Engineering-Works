JCEW Bill - Android app (Jay Chamunda Engineering Works)

Build the APK free with GitHub (no computer software needed):
1. Make a free account at github.com and create a new repository (any name).
2. Unzip this folder and upload ALL its files and folders into the repository
   (on a computer: "Add file" > "Upload files", then drag the unzipped folder contents).
3. Open the "Actions" tab. The "Build APK" job starts by itself (about 5 minutes).
4. When it shows a green tick, open it, scroll to "Artifacts" and download JCEW-Bill-APK.
5. Unzip it, copy the .apk to your phone and install (allow "Install unknown apps").

Or with Android Studio: File > Open this folder, then Build > Build APK(s).
